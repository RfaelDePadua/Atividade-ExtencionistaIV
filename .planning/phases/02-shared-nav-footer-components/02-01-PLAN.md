Create `components/nav.html` as a **pure HTML fragment** (no `<!DOCTYPE>`, no `<html>`, no `<head>`, no `<body>` — just the component markup). This file will be fetched and injected via `innerHTML` by `components.js`.

**Exact structure (in order):**

```html
<!-- Skip-to-content link (first element) -->
<a href="#main-content" class="skip-link">Pular para o conteúdo</a>

<nav class="site-nav" aria-label="Navegação principal">
  <div class="nav-container">

    <!-- Logo: planet emoji + site name in Fredoka One -->
    <a class="nav-logo" data-href="index.html" aria-label="Meu Planetinha — Página Inicial">
      <span class="nav-logo-icon" aria-hidden="true">🪐</span>
      <span class="nav-logo-text">Meu Planetinha</span>
    </a>

    <!-- Desktop nav links (hidden on mobile) -->
    <div class="nav-links">
      <a data-href="explorar/explorar.html">Explorar Jogos</a>
      <a data-href="sobre_nos/sobre_nos.html">Sobre Nós</a>
    </div>

    <!-- Desktop CTA button (hidden on mobile) -->
    <a class="nav-cta" data-href="explorar/explorar.html">Explorar Jogos</a>

    <!-- Hamburger button (visible only on mobile ≤640px) -->
    <button class="nav-hamburger" type="button"
            aria-expanded="false"
            aria-controls="mobile-nav"
            aria-label="Abrir menu de navegação">
      <span class="hamburger-bar" aria-hidden="true"></span>
      <span class="hamburger-bar" aria-hidden="true"></span>
      <span class="hamburger-bar" aria-hidden="true"></span>
    </button>
  </div>

  <!-- Mobile overlay menu (hidden by default, shown when hamburger tapped) -->
  <div class="nav-overlay" id="mobile-nav" aria-hidden="true">
    <button class="nav-overlay-close" type="button" aria-label="Fechar menu">✕</button>
    <div class="nav-overlay-links">
      <a data-href="explorar/explorar.html">Explorar Jogos</a>
      <a data-href="sobre_nos/sobre_nos.html">Sobre Nós</a>
    </div>
    <a class="nav-cta" data-href="explorar/explorar.html">Explorar Jogos</a>
  </div>
</nav>
```

**Critical details:**
- All `<a>` elements use `data-href` (NOT `href`) for navigation links. The `components.js` loader will read `data-href`, prepend the computed `BASE_URL`, and set the real `href` at injection time. This ensures links resolve correctly from any page depth.
- The logo link's `data-href` is `index.html` (root-relative from repo base).
- The hamburger button uses three `<span class="hamburger-bar">` elements (styled as three horizontal lines via CSS) — NOT the ☰ character.
- The mobile overlay duplicates the same links as desktop (same `data-href` values). This is intentional — the JS loader will rewrite all `data-href` attributes in both desktop and mobile sections.
- `aria-hidden="true"` on the overlay prevents screen readers from reading hidden menu content.
