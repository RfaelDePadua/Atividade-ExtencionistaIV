# Plan 03-01: Update gradient angle/stops and container padding

## Objective
Refine the space gradient background in `estilos/base.css` to use a slight angle (~170deg) and adjusted color stops (0%/65%/100%) so that blue dominates more of the viewport. Also update container padding breakpoints in `estilos/layout.css` to use the progressive scale: 16px mobile / 24px default / 32px desktop.

## Context
- The gradient already exists in `estilos/base.css` lines 148–155 using token indirection.
- Current values: `180deg`, stops at `0% / 50% / 100%`.
- Required values: `170deg`, stops at `0% / 65% / 100%` (per 03-CONTEXT decisions).
- Container padding in `estilos/layout.css` currently uses `--espaco-sm` (8px) at ≤480px, `--espaco-md` (16px) default, `--espaco-lg` (24px) at ≥1024px.
- Required: `--espaco-md` (16px) at ≤640px, `--espaco-lg` (24px) default, `--espaco-xl` (32px) at ≥1024px.
- Hex values behind tokens are already correct: `--cor-azul-ceu: #1A3A8F`, `--cor-indigo: #2D1B8A`, `--cor-magenta: #8B1A6B`.

## Tasks

<task id="1">
Open `estilos/base.css`. Find the body background rule (around lines 148–155):

```css
  background: linear-gradient(
    180deg,
    var(--cor-fundo-topo) 0%,
    var(--cor-fundo-base) 50%,
    var(--cor-fundo-horizonte) 100%
  );
```

Replace it with:

```css
  background: linear-gradient(
    170deg,
    var(--cor-fundo-topo) 0%,
    var(--cor-fundo-base) 65%,
    var(--cor-fundo-horizonte) 100%
  );
```

Only the angle (180deg → 170deg) and the middle stop (50% → 65%) change. Everything else stays the same.
</task>

<task id="2">
Open `estilos/layout.css`. Find the small-screen media query (around lines 26–31):

```css
/* Tighter padding on very small screens */
@media (max-width: 480px) {
  .container,
  .container-texto {
    padding-inline: var(--espaco-sm);
  }
}
```

Replace the entire block with:

```css
/* Tighter padding on small screens (mobile) */
@media (max-width: 640px) {
  .container,
  .container-texto {
    padding-inline: var(--espaco-md);
  }
}
```

Changes: breakpoint 480px → 640px, padding token `--espaco-sm` (8px) → `--espaco-md` (16px).
</task>

<task id="3">
In `estilos/layout.css`, update the default container padding. Find (around lines 10–15):

```css
.container {
  width: 100%;
  max-width: var(--largura-max-conteudo);
  margin-inline: auto;
  padding-inline: var(--espaco-md);

```

Replace with:

```css
.container {
  width: 100%;
  max-width: var(--largura-max-conteudo);
  margin-inline: auto;
  padding-inline: var(--espaco-lg);
}
```

And find:

```css
.container-texto {
  width: 100%;
  max-width: var(--largura-max-texto);
  margin-inline: auto;
  padding-inline: var(--espaco-md);
}
```

Replace with:

```css
.container-texto {
  width: 100%;
  max-width: var(--largura-max-texto);
  margin-inline: auto;
  padding-inline: var(--espaco-lg);
}
```

Default padding changes from `--espaco-md` (16px) → `--espaco-lg` (24px).
</task>

<task id="4">
In `estilos/layout.css`, update the large-screen media query. Find (around lines 34–39):

```css
/* Wider padding on larger screens */
@media (min-width: 1024px) {
  .container,
  .container-texto {
    padding-inline: var(--espaco-lg);

  }
```

Desktop padding changes from `--espaco-lg` (24px) → `--espaco-xl` (32px).
</task>
