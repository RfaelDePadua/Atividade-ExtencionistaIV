# Plan 03-05: Verify game page isolation — no gradient or style contamination

## Objective
Confirm that the two game pages under `jogos/` do NOT load any of the new design system CSS files (`reset.css`, `base.css`, `layout.css`, `componentes.css`, `components/components.css`, or the upcoming `page-shell.css`). This ensures the gradient background, star/nebula effects, and updated container padding never leak into game pages.

> **Addresses:** Phase 03 Success Criteria #5 (game pages remain isolated from design system CSS).

## Context
Game pages must be completely isolated from the site-wide design system. They use the legacy stylesheets:
- `../../estilos/geral.css`
- `../../estilos/barra_superior.css`
- Local `./estilos/principal.css`

The two game page HTML files are:
1. `jogos/Contando_Estrelas/index.html`
2. `jogos/Jogo_de_Silaba/index.html`

The new CSS files that must NOT be linked from game pages:
- `estilos/reset.css`
- `estilos/base.css`
- `estilos/layout.css`
- `estilos/componentes.css`
- `estilos/pages/page-shell.css` (will be created in 03-03)
- `components/components.css`
