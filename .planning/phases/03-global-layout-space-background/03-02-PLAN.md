# Plan 03-02: Create _template.html — canonical HTML page boilerplate

## Objective
Create a documented `_template.html` file at the project root that serves as the canonical HTML boilerplate for all site pages. It codifies the correct `<html>` attributes, meta tags, font preconnects, CSS load order (including the new `page-shell.css`), and component script loading. This template ensures consistency and is the reference for all current and future pages.

## Context
- The site's current pages (index.html, explorar.html, sobre_nos.html, 404.html) use inconsistent `<head>` blocks — some miss `lang="pt-BR"`, some use legacy CSS files, some lack preconnects.
- The canonical CSS load order (finalized after 03-01 and 03-03) is:
  1. `estilos/reset.css`
  2. `estilos/base.css`
  3. `estilos/layout.css`
  4. `estilos/pages/page-shell.css` ← NEW from 03-03
  5. `estilos/componentes.css`
  6. `components/components.css`
  7. `[page-specific CSS]`
- Font loading via `<link rel="preconnect">` + Google Fonts CSS URL
- Bootstrap Icons via CDN
- Nav/Footer components loaded via `components/components.js` at end of `<body>`
- Pages use `data-component="nav"` and `data-component="footer"` placeholders
- The template is NOT a live page — it's a reference/copy-paste starting point (prefixed with `_`)

### Existing pages that should eventually adopt this template:
- `index.html` — root depth (`href` paths: `estilos/...`, `components/...`)
- `explorar/explorar.html` — depth-1 (`../estilos/...`, `../components/...`)
- `sobre_nos/sobre_nos.html` — depth-1 (`../estilos/...`, `../components/...`)
- `404.html` — root depth (GitHub Pages serves this from root)

Game pages (`jogos/`) are EXCLUDED — they use legacy CSS and must not adopt this template.

<task id="1">
Create the file `_template.html` at the project root with the following EXACT content:

```html
<!--
  _template.html — Meu Planetinha Canonical Page Template
  ========================================================
  Copy this file when creating a new site page.
  Replace all [PLACEHOLDERS] with actual values.

  CSS Load Order (DO NOT reorder):
    1. reset.css        — CSS reset / normalize
    2. base.css         — Design tokens + base element styles
    3. layout.css       — Container, flex utilities, spacing
    4. page-shell.css   — Stars, nebulae, page-wrapper layout
    5. componentes.css  — Legacy component styles
    6. components.css   — Nav + Footer component styles
    7. [page].css       — Page-specific styles (optional)

  PATH DEPTH GUIDE:
    Root pages (index.html, 404.html):     estilos/...     components/...
    Depth-1 pages (explorar/, sobre_nos/): ../estilos/...  ../components/...

  EXCLUDED: Game pages (jogos/) do NOT use this template.
-->
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="description" content="[PAGE_DESCRIPTION — Meu Planetinha: plataforma educacional gamificada para crianças]">
  <title>[PAGE_TITLE] — Meu Planetinha</title>

  <!-- Google Fonts: preconnect + stylesheet -->
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
  <link href="https://fonts.googleapis.com/css2?family=Fredoka+One&family=Nunito:wght@400;700&family=Press+Start+2P&display=swap" rel="stylesheet">

  <!-- Bootstrap Icons -->
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.3/font/bootstrap-icons.min.css">

  <!-- CSS Load Order (do not reorder) -->
  <!-- [DEPTH]: replace paths with ../ prefix for depth-1 pages -->
  <link rel="stylesheet" href="estilos/reset.css">
  <link rel="stylesheet" href="estilos/base.css">
  <link rel="stylesheet" href="estilos/layout.css">
  <link rel="stylesheet" href="estilos/pages/page-shell.css">
  <link rel="stylesheet" href="estilos/componentes.css">
  <link rel="stylesheet" href="components/components.css">
  <!-- [PAGE_CSS]: add page-specific stylesheet here if needed -->
  <!-- <link rel="stylesheet" href="estilos/pages/[page-name].css"> -->
</head>
<body>

  <!-- Skip link (accessibility) -->
  <a class="skip-link" href="#main-content">Pular para o conteúdo</a>

  <!-- Nav component (injected by components.js) -->
  <div data-component="nav">
    <noscript>
      <nav class="site-nav" aria-label="Navegação principal">
        <div class="nav-container">
          <a class="nav-logo" href="index.html">🪐 Meu Planetinha</a>
          <div class="nav-links">
            <a href="explorar/explorar.html">Explorar Jogos</a>
            <a href="sobre_nos/sobre_nos.html">Sobre Nós</a>
          </div>
        </div>
      </nav>
    </noscript>
  </div>

  <!-- Main content -->
  <main id="main-content" class="page-wrapper">
    <div class="container">
      <!-- [PAGE_CONTENT] -->
      <h1>[PAGE_TITLE]</h1>
    </div>
  </main>

  <!-- Footer component (injected by components.js) -->
  <div data-component="footer">
    <noscript>
      <footer class="site-footer">
        <p>© 2025–2026 Meu Planetinha</p>
      </footer>
    </noscript>
  </div>

  <!-- Component loader (nav + footer injection) -->
  <!-- [DEPTH]: replace path with ../ prefix for depth-1 pages -->
  <script src="components/components.js"></script>

</body>
</html>
```
