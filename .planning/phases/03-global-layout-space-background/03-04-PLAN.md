# Plan 03-04: Contrast check on all color pairings against gradient background

## Objective
Verify that all text colors used on the gradient background meet WCAG AA Large Text (3:1) or ideally 5:1+ contrast ratio. Produce a documented contrast report. If any pairing fails, propose a fix.

> **Addresses:** Phase 03 Success Criteria #4 (all text-on-background pairings meet WCAG AA contrast).

## Context
The site uses white text (`#FFFFFF`) and various accent colors on a gradient background that transitions through three colors:
- Top: `#1A3A8F` (dark blue)
- Middle (~65%): `#2D1B8A` (indigo)
- Bottom: `#8B1A6B` (dark magenta)

All three background colors are quite dark, so white text is expected to pass. But we need to verify ALL text-on-background pairings including accent colors that appear as text.

### Contrast formula (WCAG relative luminance):
For hex color `#RRGGBB`:
1. Convert each channel to sRGB: `sR = R/255`, then linearize:
   - If `sR <= 0.04045`: `lin = sR / 12.92`
   - Else: `lin = ((sR + 0.055) / 1.055) ^ 2.4`
2. Relative luminance `L = 0.2126 * linR + 0.7152 * linG + 0.0722 * linB`
3. Contrast ratio = `(L_lighter + 0.05) / (L_darker + 0.05)`

Target: **5:1+** for body text, **3:1** minimum for large text (≥18pt / ≥14pt bold).

<task id="1">
Calculate contrast ratios for all 18 pairings listed above. You can use the WCAG relative luminance formula, or use a Node.js script, or use Python. The simplest approach is a quick Python script:

```python
def luminance(hex_color):
    hex_color = hex_color.lstrip('#')
    r, g, b = int(hex_color[0:2], 16), int(hex_color[2:4], 16), int(hex_color[4:6], 16)
    def linearize(c):
        c = c / 255.0
        return c / 12.92 if c <= 0.04045 else ((c + 0.055) / 1.055) ** 2.4
    return 0.2126 * linearize(r) + 0.7152 * linearize(g) + 0.0722 * linearize(b)

def contrast(fg, bg):
    l1, l2 = luminance(fg), luminance(bg)
    lighter, darker = max(l1, l2), min(l1, l2)
    return (lighter + 0.05) / (darker + 0.05)

backgrounds = {
    'Blue #1A3A8F': '#1A3A8F',
    'Indigo #2D1B8A': '#2D1B8A',
    'Magenta #8B1A6B': '#8B1A6B',
}

foregrounds = {
    'White #FFFFFF': '#FFFFFF',
    'Amarelo-Sol #FFD43B': '#FFD43B',
    'Laranja-Tang #FF8C42': '#FF8C42',
    'Verde-Menta #4DFFB4': '#4DFFB4',
    'Rosa-Chiclete #FF6EB4': '#FF6EB4',
    'Lilas-Algodao #C084FC': '#C084FC',
}

for fg_name, fg_hex in foregrounds.items():
    for bg_name, bg_hex in backgrounds.items():
        ratio = contrast(fg_hex, bg_hex)
        status = 'PASS 5:1+' if ratio >= 5.0 else ('PASS 3:1+ (large text only)' if ratio >= 3.0 else 'FAIL')
        print(f'{fg_name} on {bg_name}: {ratio:.2f}:1 — {status}')
```
