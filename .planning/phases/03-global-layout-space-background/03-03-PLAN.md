# Plan 03-03: Create estilos/pages/page-shell.css — stars, nebulae, and page wrapper

## Objective
Create a new stylesheet `estilos/pages/page-shell.css` that provides:
1. Static CSS-generated stars via `body::before` (multi-tinted: white, blue-ish, yellow-ish)
2. Static CSS-generated nebula blobs via `body::after` (pastel radial gradients)
3. A `.page-wrapper` class that acts as the `<main>` flex-grow container
4. Proper z-index layering so stars/nebulae sit behind all content

All effects are static — no animations per v1 requirements.

## Context
- `body` already has `display: flex; flex-direction: column;` from `components/components.css`
- `body` already has the gradient background from `estilos/base.css`
- Stars use `box-shadow` on `body::before` with `position: fixed`
- Nebulae use `radial-gradient` on `body::after` with `position: fixed`
- Both pseudo-elements use `pointer-events: none` so they don't block interaction
- Star colors: white (`#FFFFFF`), slightly blue (`#B0C4FF`), yellowish (`#FFE4B5`)
- Nebula colors: orange pastel (`#FF8C42` at ~0.06 opacity), turquoise (`#00D4E8` at ~0.05 opacity), pink (`#FF6EB4` at ~0.04 opacity)
- This file loads AFTER `layout.css` and BEFORE `componentes.css` in the CSS cascade

### Z-index layering:
- `body::before` (stars): z-index 0
- `body::after` (nebulae): z-index 0
- All page content (nav, main, footer): z-index 1+ (achieved via `position: relative; z-index: 1` on direct body children)
