State:
- `this.currentIndex = 0` — which planet is at front-center (0-4)
- `this.currentAngle = 0` — cumulative rotation angle in degrees (not clamped to 0-360 — allows smooth continuous rotation in one direction)
- `this.isAnimating = false` — animation lock
- `this.touchStartX = 0`
- `this.touchStartY = 0`

Guard: `if (!this.section || !this.orbit || this.cards.length !== PLANET_COUNT) return;`

Call `this._bindEvents()` then `this._update(false)` for initial state.

**navigate(direction) method:**
```javascript
OrbitalCarousel.prototype.navigate = function (direction) {
  if (this.isAnimating) return;
  this.isAnimating = true;

  // Update index (wraps 0-4)
  this.currentIndex = (this.currentIndex + direction + PLANET_COUNT) % PLANET_COUNT;

  // Update cumulative angle (negative = clockwise visual rotation to bring next planet forward)
  // direction +1 (next) → subtract STEP_DEG (rotate ring clockwise so next planet comes to front)
  // direction -1 (prev) → add STEP_DEG (rotate ring counter-clockwise)
  this.currentAngle -= direction * STEP_DEG;

  this._update(true);

  var self = this;
  setTimeout(function () {
    self.isAnimating = false;
  }, TRANSITION_MS);
};
```

**goTo(index) method:**
```javascript
OrbitalCarousel.prototype.goTo = function (index) {
  if (this.isAnimating) return;
  if (index < 0 || index >= PLANET_COUNT) return;
  if (index === this.currentIndex) return;

  this.isAnimating = true;

  // Calculate shortest rotation path
  var diff = index - this.currentIndex;
  // Normalize to -2..+2 range for shortest path around ring
  if (diff > 2) diff -= PLANET_COUNT;
  if (diff < -2) diff += PLANET_COUNT;

  this.currentIndex = index;
  this.currentAngle -= diff * STEP_DEG;

  this._update(true);

  var self = this;
  setTimeout(function () {
    self.isAnimating = false;
  }, TRANSITION_MS);
};
```

**_update(announce) method — THE CORE:**
This method does three things:
1. Sets `--orbit-angle` on `.carousel-orbit` → CSS transition animates the ring
2. Sets `data-orbit-zone` on each planet card → CSS attribute selectors apply styling
3. Updates ARIA attributes and announcer

```javascript
OrbitalCarousel.prototype._update = function (announce) {
  var ci = this.currentIndex;

  // 1. Set orbit angle — CSS transition handles smooth rotation
  this.orbit.style.setProperty('--orbit-angle', this.currentAngle + 'deg');

  // 2. Assign zones per planet
  for (var i = 0; i < this.cards.length; i++) {
    var card = this.cards[i];

    // Calculate offset from center (0 = center, ±1 = side, ±2 = back)
    var offset = (i - ci + PLANET_COUNT) % PLANET_COUNT;
    // Normalize: 0=center, 1=side-right, 2=back-right, 3=back-left, 4=side-left
    var zone;
    if (offset === 0) {
      zone = 'center';
    } else if (offset === 1 || offset === PLANET_COUNT - 1) {
      zone = 'side';
    } else {
      zone = 'back';
    }

    card.setAttribute('data-orbit-zone', zone);

    // ARIA: center card visible + focusable, others hidden
    if (zone === 'center') {
      card.removeAttribute('aria-hidden');
      card.setAttribute('tabindex', '0');
    } else {
      card.setAttribute('aria-hidden', 'true');
      card.setAttribute('tabindex', '-1');
    }
  }

  // 3. Update data-active-planet on section
  var activePlanet = PLANETS[ci];
  this.section.dataset.activePlanet = activePlanet.slug;

  // 4. Update dots
  var accentVar = 'var(--planeta-' + activePlanet.slug + '-acento)';
  for (var d = 0; d < this.dots.length; d++) {
    var dot = this.dots[d];
    if (d === ci) {
      dot.classList.add('carousel-dot--active');
      dot.style.setProperty('--dot-color', accentVar);
      dot.setAttribute('aria-current', 'true');
    } else {
      dot.classList.remove('carousel-dot--active');
      dot.style.removeProperty('--dot-color');
      dot.removeAttribute('aria-current');
    }
  }

  // 5. Announce to screen readers
  if (announce && this.announcer) {
    this.announcer.textContent =
      'Planeta ' + activePlanet.name + ', ' + activePlanet.subject +
      '. ' + (ci + 1) + ' de ' + PLANET_COUNT + '.';
  }
};
```

**_bindEvents() method:**
Bind ALL of these event handlers:

1. **Arrow buttons** — `prevBtn.click` → `navigate(-1)`, `nextBtn.click` → `navigate(1)`

2. **Keyboard** — scoped to `#carousel` `keydown`:
   - `ArrowLeft` → `navigate(-1)`
   - `ArrowRight` → `navigate(1)`
   - `Home` → `goTo(0)`
   - `End` → `goTo(PLANET_COUNT - 1)`
   - `Enter` or `Space` on `.planet-card[data-orbit-zone="center"]` → trigger click (planet selection)

3. **Touch swipe** — scoped to `.carousel-scene` (NOT `.carousel-orbit` which is a 0×0 element):
   - `touchstart` (passive) → record `clientX`, `clientY`
   - `touchend` (passive) → calculate deltaX/deltaY, if horizontal swipe > threshold: `deltaX < 0` → `navigate(1)`, `deltaX > 0` → `navigate(-1)`

4. **Dot clicks** — each dot → `goTo(index)`

5. **Side planet clicks** — on each card click, check `data-orbit-zone`:
   - If `"center"` → dispatch `planet-selected` custom event with `{ detail: { planet: slug } }`, bubbles: true on `this.section`. Then move focus to `#jogos .jogos-titulo` if it exists.
   - If `"side"` → determine if this planet is the "next" or "prev" side planet and navigate accordingly. Calculate: `var offset = (cardIndex - this.currentIndex + PLANET_COUNT) % PLANET_COUNT;` — if offset === 1, `navigate(1)`; if offset === PLANET_COUNT - 1, `navigate(-1)`.

6. **Center planet Enter/Space** — already handled in keyboard section above.
