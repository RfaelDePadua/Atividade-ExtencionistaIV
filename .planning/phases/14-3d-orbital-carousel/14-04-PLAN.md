  <what-built>Complete 3D orbital planet carousel replacing the v1 flat carousel. Planets orbit on a tilted 3D ring with perspective-based size scaling, fade/blur on back planets, and smooth 600ms rotation transitions.</what-built>
  <how-to-verify>
    1. Run: `python -m http.server 8000` (or use existing server)
    2. Visit: http://localhost:8000/index.html

    **Visual checks:**
    3. Carousel should render as a tilted 3D ring — planets arranged in an elliptical orbit, NOT in a flat horizontal row
    4. Center planet should be noticeably LARGER than side planets (~65% size difference from natural CSS perspective)
    5. Two back planets should be ghostly/faded (~30% opacity) and slightly blurred
    6. Back planets should have NO visible name labels; front + side planets should show labels

    **Interaction checks:**
    7. Click right arrow (›) — ring should rotate smoothly (~600ms ease-out), bringing next planet to center
    8. Click left arrow (‹) — ring rotates opposite direction
    9. Click a side planet — should navigate to that planet (acts as prev/next)
    10. Click dot indicators below carousel — should jump to that planet
    11. Click center planet — game grid section below should receive focus, indicating planet selection works

    **Keyboard checks:**
    12. Click on carousel section to focus it
    13. Press Right arrow key — next planet
    14. Press Left arrow key — previous planet
    15. Press Home — first planet (Calculon)
    16. Press End — last planet (Globish)
    17. Press Enter on center planet — should trigger selection (game grid focus)

    **Responsive checks:**
    18. Resize browser to ~768px width — orbit should shrink, planets smaller
    19. Resize to ~480px width — further shrink, tighter arrows

    **A11y checks:**
    20. Active dot should be colored with planet accent color and have aria-current="true"
    21. Turn on screen reader (or inspect DOM) — non-center cards should have aria-hidden="true"
    22. Announcer region should update text on each navigation

    **Browser checks:**
    23. Test in Chrome — should work fully
    24. If available, test in Safari — check that 3D perspective renders correctly (no flattening)
    25. If available, test in Firefox — confirm transitions are smooth
