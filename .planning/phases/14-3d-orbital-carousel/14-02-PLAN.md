**Section 3: Carousel Orbit (3D rotating ring)**
```css
.carousel-orbit {
  position: absolute;
  top: 50%;
  left: 50%;
  width: 0;
  height: 0;
  transform-style: preserve-3d;
  transform:
    translate(-50%, -50%)
    rotateX(calc(-1 * var(--orbita-inclinacao)))
    rotateY(var(--orbit-angle, 0deg));
  transition: transform var(--orbita-rotacao-duracao) var(--orbita-easing);
  will-change: transform;
  overflow: visible; /* Safari safeguard */
}
```
Key points:
- `width: 0; height: 0` — orbit is a virtual point; planets are pushed out by `translateZ`
- `--orbit-angle` defaults to `0deg`; JS updates it. CSS transition handles smooth interpolation
- `rotateX(-25deg)` tilts the ring for the orbital plane view
- This is the ONLY `will-change` element for the carousel (GPU budget: 3 total = 2 starfield + 1 orbit)

**Section 5: Zone-based styling via `data-orbit-zone` attribute**
JS sets `data-orbit-zone` to "center", "side", or "back" per planet on each navigation step. CSS attribute selectors handle all visual treatment.

```css
/* CENTER — fully visible, interactive */
.planet-card[data-orbit-zone="center"] {
  opacity: 1;
  filter: blur(0);
  z-index: 3;
  pointer-events: auto;
  cursor: pointer;
}

/* SIDE — visible, clickable (act as prev/next) */
.planet-card[data-orbit-zone="side"] {
  opacity: 0.7;
  filter: blur(0);
  z-index: 2;
  pointer-events: auto;
  cursor: pointer;
}

/* BACK — ghostly, NOT clickable */
.planet-card[data-orbit-zone="back"] {
  opacity: var(--orbita-opacidade-fundo);
  filter: blur(var(--orbita-blur-fundo));
  z-index: 1;
  pointer-events: none;
}
```
