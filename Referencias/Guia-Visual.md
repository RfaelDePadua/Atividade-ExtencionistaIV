**MEU PLANETINHA**

Guia de Identidade Visual

Plataforma de jogos educacionais · Público: 6–10 anos

**_"Aprender é uma aventura!"_**

**01 · Background do Site**

**Direção escolhida: Cosmos Colorido**

**Descrição Visual**

O fundo do site é um gradiente vibrante que remete ao espaço de forma alegre e imersiva, evocando aventura espacial desde o primeiro segundo de visita.

|     |     |
| --- | --- |
| **Gradiente principal** | Topo: Azul-céu médio #1A3A8F → Base: Índigo vibrante #2D1B8A → Horizonte: Magenta suave #8B1A6B |
| **Estrelas** | Coloridas (brancas, levemente azuis, amareladas), tamanhos variados, com drift lento |
| **Nebulosas** | Laranja pastel, turquesa e rosa — difusas, como bolhas de tinta na água |
| **Movimento** | Drift lento das estrelas, como se a criança estivesse viajando pelo espaço devagar |
| **Sensação** | Planetário colorido, ilustração de livro infantil moderno — animado e vibrante |

**04 · Header**

**Direção escolhida: Minimal Espacial adaptado · Comportamento: Fixo que encolhe ao rolar**

|     |     |
| --- | --- |
| **Comportamento** | Fixo no topo; encolhe suavemente ao rolar a página (logo menor, navegação compacta) |
| **Fundo** | Transparente no topo da página → escurece suavemente para #0D1A3A ao rolar |
| **Logo (esquerda)** | Ícone do planeta + "Meu Planetinha" em Fredoka One, tamanho médio, compacto |
| **Navegação (direita)** | Jogos · Conquistas · Sobre · Entrar — Nunito Bold, texto puro com underline animado em magenta no hover |

**06 · Carrossel de Planetas**

**Estilo: Órbita Central · Animação: Flutuação (sobe e desce em loop)**

**Mecânica do Carrossel**

|     |     |
| --- | --- |
| **Disposição** | Planeta central em destaque (maior), planetas laterais menores e desfocados |
| **Animação loop** | Flutuação suave — cada planeta em ritmo levemente diferente (não mecânico) |
| **Hover / Toque** | Planeta pulsa e cresce, solta partículas da sua cor característica |
| **Navegação** | Setas em formato de foguete apontando para os lados |
| **Label do planeta** | Nome em Fredoka One abaixo + subtítulo curto de convite em Nunito |

**Identidade Visual de Cada Planeta**

**07 · Botões e Elementos Interativos**

**Estilo: Cápsula Espacial · Interações: Hover sobe, Click afunda + partículas, Cor por contexto**

|     |     |
| --- | --- |
| **Formato** | Oval/pílula generoso — bem arredondado, bastante padding interno |
| **Botão primário** | Gradiente diagonal da cor do contexto (planeta atual). Default: amarelo-sol #FFD43B → laranja-tang #FF8C42. Brilho interno no topo (efeito 3D). Texto Nunito Bold branco. |
| **Botão secundário** | Fundo transparente, borda 2px na cor do contexto, texto colorido. Hover: preenche com a cor. |
| **Estado Hover** | Sobe 3px + sombra cresce — sensação física de botão real |
| **Estado Click** | Afunda 2px + partículas explodem do centro por ~0.3s |
| **Cor contextual** | Calculon: laranja · Letrion: lilás · Naturox: verde · Terramund: laranja-terra · Globish: ciano |
| **⭐ Badges de conquista** | Estrela de 5 pontas com gradiente dourado, fonte Press Start 2P no número/texto interno |
| **⭐ Barra de progresso** | Gradiente da cor do planeta, com pulso suave de brilho em loop |

**08 · Cards e Tela de Jogo**

**Card: Portal de Entrada · Tela interna: Imersão Total**

**Card de Jogo — Portal de Entrada**

|     |     |
| --- | --- |
| **Formato** | Retangular com cantos muito arredondados |
| **Fundo** | Cor dominante do planeta em gradiente — cada card tem identidade visual própria |
| **Metade superior** | Ilustração do planeta flutuando — grande, em destaque, com animação de flutuação |
| **Metade inferior** | Nome do jogo (Fredoka One) + dificuldade em estrelinhas (1–3) + botão "Jogar!" contextual |
| **Base do card** | Barra de progresso discreta — quantos desafios já foram completados naquele jogo |
| **Hover** | Card inteiro sobe + planeta pulsa — como se o portal dimensional estivesse se abrindo |

**Tela Interna de Jogo — Imersão Total**

|     |     |
| --- | --- |
| **Layout** | Jogo ocupa 100% da tela — imersão total, sem distrações |
| **HUD** | Flutuante minimalista no topo — bolhas semi-transparentes com: pontuação, vidas, botão de sair |
| **Pontuação / Placar** | Fonte Press Start 2P — momento especial de game dentro da tela de jogo |
| **Background in-game** | Versão mais escura/saturada da cor do planeta — o universo some, só existe o desafio |
